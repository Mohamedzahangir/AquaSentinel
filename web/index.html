AquaSentinal — Data Provenance & Engineering Specification

1. Source Material & Georeferencing

The dataset is derived from 107 Greater Chennai Corporation (GCC) / SECON-JBA base map sheets (2021 survey, World Bank PDGF flood-forecasting project). The source sheets were vector CAD drawings containing AutoCAD SHX font glyphs without selectable text or standard GeoPDF tags.

Every coordinate is computed by least-squares fitting the 500 m UTM grid lines printed on each sheet (median residual: 4.7 cm). Data is maintained natively in EPSG:32644 (WGS 84 / UTM zone 44N).

3. Hydraulic Modeling Context

The SWMM dynamic wave routing model represents an uncalibrated engineering diagnostic. When scored against the December 2015 flood record, the extracted network demonstrates where dead ends and reverse sumps create waterlogging, isolating survey gaps from drainage capacity.
